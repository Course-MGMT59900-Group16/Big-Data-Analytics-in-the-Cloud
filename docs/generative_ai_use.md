# Generative AI Use Note

We used generative AI tools, including ChatGPT and Microsoft Copilot, along with Grammarly for editing support.

We used AI for:

- brainstorming architecture and analysis ideas;
- troubleshooting AWS configuration issues;
- refining SQL/query structures;
- helping interpret query outputs;
- improving clarity and organization in the report and presentation.

Our group executed the Glue crawler and ETL job, ran the Athena queries, reviewed the Bronze/Silver/Gold outputs, and confirmed the data-quality and analytical findings.

QuickSight dashboarding and model training are treated as planned extensions rather than completed implementation.

We remain responsible for the final architecture decisions, interpretations, and submitted work.
