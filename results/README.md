# Verified Analytical Results

These CSVs contain the summary values used in the report and presentation.

They are small outputs from the Athena analysis, not the raw source data.

Important interpretation notes:

- Annual/state values are dataset record counts, not population- or exposure-adjusted accident rates.
- 2023 is excluded from full-year trend comparisons.
- `high_impact` means Severity 3-4 in the source traffic-impact scale.
- Association results do not establish causation.
- The weather summary includes a `MISSING/BLANK` category because weather-condition values were missing for some records.
